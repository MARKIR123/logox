## 2. 延续性边界

- 动态扩展 Schema 的变化尚没有独立的完整上下文状态指纹；提供商切换、Anthropic 思考签名及恢复兼容需继续覆盖。
- 原始会话、工具归档与有效模型视图各有作用；仍存在部分工具内容重复存储和扫描开销。优化应保留溯源、恢复与审计证据。
- 权限与只读入梦均不构成操作系统沙箱。多文件恢复和用户/项目记忆更新不保证跨文件整体原子提交。
- MCP 当前提供 stdio 路径；传输扩展、自动实验、忙时排队等不能作为已实现能力介绍。

这些边界的机制以所属模块为准；这里用于安排后续工作，不维护另一份接口说明。
