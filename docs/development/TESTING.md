# 验证与测试

核对日期：2026-10-09。本文说明执行方法；某次通过数量属于当时的验收记录，不作为永久基线。

## 1. 环境与执行入口

支持的 Python 版本、开发依赖、测试发现和缓存设置以 [pyproject.toml](../../pyproject.toml) 为准；精确依赖由 uv.lock 锁定。在仓库根目录执行：

```powershell
uv sync --extra dev
uv run python -m pytest -q tests/tui/test_keymap.py
```

第二条是一次定向验证示例。实际任务选择相关测试；跨模块变更需要时运行全量回归：

```powershell
uv run python -m pytest tests
```

[test configuration](../../tests/conftest.py) 将临时目录放进忽略的 .test-tmp，移除继承的 *_API_KEY，并限制仓库内测试对外部祖先项目的发现。它没有隔离整个操作系统或所有用户配置；新增测试仍须使用临时路径、替身模型和明确配置，避免访问私人会话、真实凭据或服务。

需要 ripgrep 的测试先执行 `rg --version`。缺少工具导致的跳过与验证通过分别报告。开发依赖未包含所有静态检查工具，不能假定系统已安装 ruff 或 mypy。

## 2. 按行为选择验证

| 改动 | 应验证的结果 | 入口 |
|---|---|---|
| 单轮调度、响应终止、取消 | 只执行完整工具参数；工具调用与结果配对；异常、取消均到终态；限制跨恢复请求仍生效 | tests/unit、tests/contract |
| 上下文与存储 | 压缩后的有效视图可恢复；未知时间不补造；上下文与原始历史区分；冲突和部分恢复如实报告 | tests/unit、tests/e2e |
| 权限与工具 | 正常装配也经过审计；敏感路径和复合命令边界；工具超时、取消、结果裁剪 | tests/unit、tests/contract |
| TUI | 输入、流式内容、工具卡片及阅读位置；主屏与全屏分别覆盖 | tests/tui |
| Anamnesis | 多窗口协调、固定会话归属、暂停续做、进度落盘、条目核验、版本冲突与重复自检 | tests/anamnesis |
| 文档 | 有效路径、命令和示例；当前说明不混入历史；公开材料不依赖忽略的私人原文 | 文档静态检查与现有文档守卫 |

测试目录按已有用例组织。查找相关测试时从行为名、事件名或接口名搜索，避免仅因文件相邻就认定覆盖完整。替身（fake）提供可控制的模型或终端结果，用于验证逻辑；它无法证明真实服务的性能和协议细节。

文档键位守卫可单独运行：

```powershell
uv run python -m pytest -q tests/tui/test_keymap.py -k ui_spec_mentions_no_removed_keys
```

## 3. TUI 性能与真实终端

已有 [离线基准](../../tools/benchmark_tui.py) 使用 FakeTerminal 和合成历史，不接触模型或用户状态：

```powershell
uv run python tools/benchmark_tui.py --pairs 100 800 3200 --frames 15
```

输出是各模式输入与流式场景的单帧 median/max 毫秒数；`--profile` 补充调用耗时。计时不包含物理终端、网络和全部按键链路，不能当作用户感知延迟。

真实 Windows Terminal 至少检查：

- 空白与长历史中，空闲、模型输出及工具运行时的输入和发送显示。
- 工具动画、计时与流式文字是否连续更新。
- 往上阅读时新增工具、展开/收起思考和卡片、调整窗口尺寸后的历史与阅读位置。
- 主屏原生滚动历史和全屏应用视口分别验收；主屏滚出物理屏的旧卡片保留当时快照。

记录终端、窗口尺寸、历史规模、模型与工具状态、触发步骤以及测量方式。主屏启动清理此前的终端历史，与运行期间的历史保持是两种行为。

## 4. 模型、MCP 与入梦的现场验收

厂商适配的离线测试不能证明真实模型会遵守摘要、思考或提案契约。现场使用单独测试项目和非私人输入，记录模型完整名称、服务版本、声明窗口与终止原因。

入梦现场检查：实时分析及动画、阶段结论、暂停后续做、resume 恢复原卡片、多会话归属，以及只采纳具备依据且核验通过的记忆。模型未返回思考时界面不能编造。超时应注明是连续无响应、用户中止还是服务终止。

MCP 现场检查 stdio 服务启动、目录发现、工具调用、取消与进程清理。当前不支持的传输不能以离线测试成功代替支持声明。
