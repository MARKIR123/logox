# 权限、会话与文件恢复

核对日期：2026-10-09。审批控制执行范围，快照提供恢复依据；两者都有明确边界。

## 权限选择

普通工作区只读通常静默允许。敏感路径、越界或风险命令显示工具、参数、风险原因和可选授权范围。Esc/取消表示拒绝，不默认继续执行。

default 对未匹配普通操作询问；creative 自动允许常规动作，仍保留已识别黑名单、deny 和高风险确认。已有允许规则可避免重复询问，不构成无条件全放行。用 /permissions 查看与撤销规则，/mode 查看或切换模式。

权限审计是应用策略，已批准 Shell 可运行本机代码；插件、Hook 和外部服务也不受系统级隔离。不要将风险提示当作所有副作用可检测或可撤销。

## 保存与继续会话

logox 默认继续当前项目最近会话；--new 新建，--resume 选择。运行中 /resume 切会话，/new 创建干净会话。会话选择器可软删除，实际删除动作先核对目标。

原始对话、工具输出、摘要、压缩状态和入梦引用分别保存。压缩后恢复会校验有效分支并恢复折叠视图，时间线仍显示原始有效对话。旧日志从未保存的压缩正文无法凭计数还原；缺失状态时如实回到原历史。

工具中断后可以继续提问。恢复会话时，缺少结果的工具调用会自动补成“未返回结果”的失败记录，避免下一次请求因消息不完整而失败；不会自动重跑命令。

记录 timestamp 为事件时刻，旧记录未知为 null。请求结束前的流式增量在内存，异常退出或写入失败可能丢失；程序继续不代表保存成功。持久数据默认在 ~/.logox/sessions、blobs 和 anamnesis。

## 文件回滚

/rewind 打开检查点，参数是列表序号；选择目标轮次后撤销该轮及之后的受支持文件修改。/undo 使用最近检查点。回滚还会调整有效对话分支，避免模型继续相信被撤销的修改。

write/edit 有文件前后快照，任意 Shell、MCP、手工编辑或外部服务副作用不自动覆盖。纯对话检查点不能凭空恢复未保存文件。

出现外部修改冲突时，默认终止保留物理文件；明确选择强制覆盖才恢复快照，该选择会覆盖手改。缺失或损坏快照预检失败不执行。执行中可能部分成功，报告成功路径和失败原因，未整体成功时不提交对话回滚。

单文件替换有原子边界，多文件与日志没有整体事务。保留重要项目与用户数据备份，不能把 /undo 当成任意命令的一键撤销。

## 入梦档案的恢复边界

入梦有独立版本、准备记录和过程；用户/项目分别提交。手工改过档案或机器版本不匹配时，保留提案并停止自动覆盖。

/undo 不撤销记忆。当前仅有内部 ArchiveStore.revert API，没有 slash 档案撤销/手工接管界面；不要按旧说明寻找不存在的命令。入梦 history/report/trace 查询方式见 [指南](anamnesis.md)。
