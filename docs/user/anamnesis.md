# Anamnesis 入梦

核对日期：2026-10-09。当前为统一只读流程，没有昼夜模式或固定总时长。

## 它做什么

TUI 打开时，LOGOX 可在项目空闲后回顾本项目有效会话、按问题阅读代码，整理用户事实、偏好和项目进展。先提出变更，再检查来源及独立核验，合格条目进入活档案，证据不足留候选。

用户档案为 ~/.logox/ANAMNESIS.md，项目档案为当前工作目录/ANAMNESIS.md；过程存于 ~/.logox/anamnesis。它们是自动背景资料，与人工 LOGOX.md 规则分开，后续请求按预算加载。

模型不能改源码、执行 Shell/测试或使用 MCP/插件。建议“下一步测试”不等于已经执行测试，候选“已完成”不等于已经入档。

## 配置本地模型

先启动 Ollama 或 LM Studio，核对可用模型和服务实际启用窗口。在用户 config.toml 合并：

```toml
[providers.ollama]
kind = "openai_compat"
base_url = "http://127.0.0.1:11434/v1"
api_key_env = ""
models = ["qwen3.8:27b"]
context_window = 32768

[anamnesis]
enabled = true
memory_enabled = true
provider = "ollama"
model = "qwen3.8:27b"
idle_seconds = 1800
request_timeout_s = 180
```

模型和窗口是示例，替换实际值；至少 4096。已有提供商段请合并，不重复 TOML 表。配置值不检测实际服务容量；此功能拒绝远端、代理和重定向，没有云端兜底。

重启加载配置。之后 /anamnesis model 选模型，/anamnesis model <名称> 直接选择，/anamnesis model refresh 刷新当前入梦供应商目录。选择保存独立 state，下次入梦生效，不改变前台 /model；运行、准备或暂停收尾中拒绝切换。

## 触发与暂停

默认项目所有存活窗口都空闲超过 30 分钟，前台整轮模型、工具、审批结束，才自动启动。按最后活动与任务结束较晚时刻计算。手动 /anamnesis 跳过空闲等待，仍遵守项目忙状态与运行锁。

单项目多会话只在最近提交会话展示；多项目按最近提交从新到旧串行。卡片启动后固定归属，不因其它会话新指令搬家。其它窗口提交不停止当前窗口的入梦。

编辑未发送草稿、粘贴、浏览和展开不暂停当前入梦，只影响下次资格。发送普通消息或 /anamnesis stop 暂停当前窗口；关闭 TUI 停止并收尾，不在后台守护。--chat 不启动自动入梦。

无新资料或恢复事项不重复研究；精确重复而无进展会提醒自检，仍无进展保护暂停。没有整次时长/总轮数/固定生成额度，但本地服务额度仍可能截断，默认连续 180 秒没有模型数据才停止；持续思考/正文/参数分片会延长等待。

## 查看过程与结果

| 命令/按键 | 用途 |
|---|---|
| Ctrl+T | 与普通思考共用，展开入梦事项、实际思考、阶段依据和变更 |
| /anamnesis status | 当前阶段、模型、原因、剩余资料和跳过的背景 |
| /anamnesis history | 当前项目所有运行及所属会话 |
| /anamnesis report [run_id] | 完整分析、采纳/候选、变更和下一步 |
| /anamnesis trace [run_id] | 完整原始过程，包括读取、响应和错误 |
| /anamnesis stop | 请求暂停并保留完成分析 |

活动动画表示任务仍运行，不保证已收到思考。模型未返回 reasoning 时界面不会编造；阶段说明完整返回后展示。头部计时含暂停，不是纯计算耗时。

完成/失败/暂停停止动画并通知；正常批次交接显示等待续做，继续仍用同卡片。resume 原会话恢复卡片，旧无归属记录只在 history。预览有节选，完整 report/trace 不丢给前台提示词；主屏屏外卡片仍保留旧终端快照。

## 怎样判断记忆是否可靠

宿主检查来源身份、分析包含关系、项目范围、时间/当前文件和版本，再由同一本地模型独立请求核验。模型自称完成不是证据，独立请求也不意味着零误判。

明确用户原话可支持稳定偏好；当前项目状态需新有效依据。旧记录时间未知保留 null，不直接当过期或今天。完整批次可部分采纳或全为候选；游标推进只表示已经审阅。

用户/项目档案默认正文预算 800/1600 估算 tokens，前台自动背景总量默认最多窗口 5%，放不下整份跳过。memory_enabled 关闭前台加载，enabled 控制调度；context.project_memory_enabled 额外关闭项目档案，不关闭用户档案。

手工修改或版本不匹配时自动写入停止，提案留报告。没有 slash 档案撤销和手工接管界面。当前没有经过本轮真实模型对照证明的召回率、token 或工具量改善指标，机制详见 [入梦模块](../modules/09_anamnesis.md)。
