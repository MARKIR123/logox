# TUI 布局与交互契约

核对日期：2026-10-09。面向界面实现者；运行方式与操作步骤见 [用户交互指南](user/interaction.md)，渲染机制见 [TUI 模块](modules/03_tui.md)。

## 布局与终端模式

主屏按消息、临时提示/补全、输入框、状态栏顺序流式排列，使用终端原生回滚和选择；不为固定高度人工填满空行。全屏使用备用屏，输入区和状态栏停靠底部，消息视口独立滚动，预留一列给滚动条。

输入高度随内容增长并受屏幕空间约束，浮层和补全应保留可操作区域。窄终端优先保证输入、错误和退出路径，表格与长内容按显示格换行/裁剪。中文和组合字形不能按字符串长度直接计算宽度。

原生硬件光标用于输入与中文候选定位；模式退出恢复光标、键盘和鼠标状态。全屏临时鼠标/选择处理不改变主屏终端原生行为。

## 色彩与结构

组件使用主题语义 token，不把色值散落在业务逻辑。普通内容主要以前景色、缩进、轨道和边框分层；状态还需文字/符号，不能只靠颜色表达成功或失败。

内置 logox-dark、logox-light、logox-contrast。主题采用 TOML，用户同名文件覆盖内置；项目主题目录不参与发现。Schema 缺项或格式错误拒绝该主题；启动回退内置并提示，切换失败保留当前主题。

对比度检查以正文 4.5:1、次要文本 3:1、高对比主题正文 7:1 为基线；用户自定义对比度不足给警告，不强行改色。字段及计算以 [主题校验](../src/logox/config/theme.py) 为准，操作见 [主题指南](user/themes.md)。

ui.icon_set 支持 unicode/ascii/nerd；字形从主题和覆盖函数传到卡片与状态，不在组件各自维护副本。Nerd 字体由终端环境提供。动画启用与否都保留明确终态。

## 消息与卡片

| 组件 | 显示要求 | 交互与终态 |
|---|---|---|
| 用户消息 | 清楚显示已接受文本，只插入一次 | 在后续上下文准备前显示一帧 |
| 助手正文 | Markdown、代码、表格和链接，正文不因摘要提取丢失 | 流结束/取消排空缓动 |
| 推理 | 明确区别于正文，默认收起 | Ctrl+T，全局与单块覆盖语义一致 |
| 工具 | 名称、摘要、耗时及运行/成功/失败状态 | Ctrl+O 展开参数、结果/Diff；失败初次展开，仍可收起 |
| 入梦 | 每个 run_id 单卡片，绑定启动会话 | Ctrl+T 展开实际思考、阶段、依据、候选和变更 |
| 通知 | 清楚说明失败、取消或保存异常 | 不抢输入焦点，历史回放不重复终态通知 |
| 状态栏 | 当前模型/思考、有效上下文、吞吐和缓存等配置项 | 未知显示未知，估算和服务实测不能混写 |

工具 display 和模型 content 是不同输出通道；界面不能用短 digest 替代展开后的完整参数/结果。Diff 表示工具报告，不证明后续测试通过。

入梦活动头部动画表示仍运行，终态停止；正常批次交接显示等待续做。思考与阶段正文缓存，动画计时不重排全部长文。模型未返回思考时展示等待，不编造内心过程；完整外置记录入口为 report/trace。

## 输入、焦点与审批

Enter 提交；候选列表存在时先处理补全。Ctrl+J/Ctrl+Enter 的 LF 换行和行尾反斜杠退路保留；Shift+Enter 取决于终端是否提供修饰位。粘贴作为一次插入，不逐行自动发送。

焦点优先顺序为浮层、输入/补全、时间线控制。Esc 先处理浮层筛选/关闭，审批里取消为拒绝；无浮层且前台忙时中断。Ctrl+C 前台忙时中断，空闲时两次退出；Ctrl+D 无浮层时退出。

Ctrl+O 工具/Diff、Ctrl+T 推理/入梦、Ctrl+B 轨道互不混用。全文键位以实际处理器与 /help 联合核对；帮助声明若落后于实现，记录差异，不为文档改写行为。

审批显示工具、实际参数、风险原因和授权范围。默认选择避免误批准，等待以 Future 暂停工具而非整个输入任务；关闭解除等待，不默许执行。

模型请求结束后工具仍可继续，所以模型/会话/资源操作守卫以整轮 busy 判定。入梦唤醒只由真实提交或 stop，编辑草稿仍可继续后台任务。

## 滚动与缓存正确性

全屏阅读位置按消息块和块内行保持；只有底部跟随新内容。工具开始/完成、增量、展开、浮层、输入高度和终端尺寸变化使用一致宽度与锚点。点击范围、选择与实际显示行同步。

主屏启动清理此前的终端回滚历史；运行期间正常刷新保留 LOGOX 历史，已滚出屏的卡片保留当时画面；当前画面与报告更新。终端缩放和原生重排需要现场验证，不承诺屏外旧状态可原地修改。

缓存必须包含所有影响显示的内容和几何条件；只用对象身份会漏掉原地工具状态变化。展开或主题变化重新计算相关块；不丢行、不重复行、不显示旧结果是先于缓存命中率的条件。
