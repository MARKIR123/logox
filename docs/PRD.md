# LOGOX 产品需求与范围

核对日期：2026-10-09。本文维护当前产品边界；实现机制见模块文档，操作见用户指南。

## 产品定位

LOGOX 是面向开发者的终端编程助手，参考 Pi Agent 的轻量可组合设计与 Claude Code 的权限交互。用户在项目目录用自然语言描述任务，模型通过文件/命令工具工作，界面展示输出、工具进度、审批和恢复入口。

目标是支持可继续、可追溯的编程工作流，并在空闲时用本地 Anamnesis 整理跨会话背景。当前不保证模型生成代码正确、需求全部满足或记忆零误差；用户仍需检查实际结果。

## 产品概念

| 概念 | 在 LOGOX 中的含义 |
|---|---|
| 项目 | 规范工作目录对应的会话桶与状态范围，不等同程序安装目录 |
| 会话 | 一份可恢复的对话历史；同项目可有多个会话 |
| 轮次 | 一次真实用户指令至完成、失败或取消，可能包含多次模型请求 |
| 上下文 | 当前实际发送模型的规则和消息视图，不等同完整会话日志 |
| 人工规范 | 用户维护的 LOGOX.md 等规则，独立于自动背景记忆 |
| Anamnesis 入梦 | TUI 开启时，空闲或手动触发的本地只读回顾、研究和记忆核验流程 |
| 研究事项/清单 | 有明确问题与完成边界的本次工作；只追加必要前置依赖 |
| 前置依赖 | 为回答已登记问题必须先解决的相关问题，附父事项和必要性理由 |
| 后续建议 | 无需为本次结束强制执行的发现或优化方向，不自动扩成任务 |
| 停滞提醒 | 相同研究请求和结果重复且无实际进展时，宿主要求模型自检；不是进展本身 |
| 等待依据 | 当前无法可靠判断，说明缺少什么；允许结束当前研究，不表示问题已解决 |
| 记忆候选 | 未通过或尚不足以入档的条目，只保留在报告/过程，不加载为事实 |

入梦已统一，不区分昼夜或小憩/长眠权限。日期、档案状态和模型声明不单独构成事实证据。

## 当前能力

| 用户目标 | 已实现路径 | 可观察结果 |
|---|---|---|
| 在终端完成任务 | 主屏/全屏 TUI、流式输出、六个文件/命令工具 | 可输入、浏览工具与思考，并查看终态 |
| 控制执行范围 | 应用风险审计、规则、人工询问、权限模式 | 显示允许/拒绝/询问及原因 |
| 处理异常结束 | 保留增量、工具结果配对、响应分类、有界截断恢复 | 明确区分完成、失败与取消 |
| 控制长历史规模 | 工具归档、随轮摘要复用、极小窗口本地汇总 | 显示有效占用并保留回读路径 |
| 继续和撤销工作 | 会话 resume、压缩状态恢复、write/edit 快照及回滚 | 恢复有效历史，冲突和部分失败可见 |
| 自定义连接和资源 | Provider、主题、Skill、模板命令、插件、Hook、stdio MCP | 按配置发现，按需载入或连接 |
| 减少重复背景整理 | 本地入梦、用户/项目活档案、提案和独立语义核验 | 一张可展开卡片，保存报告/过程，后续请求按预算加载 |

六个内置工具为 read、write、edit、glob、grep、shell；默认配置中的 todo 没有内置实现。/files 和 /memory 仍为计划命令。日志与模型窗口为运行数据/配置约束，不承诺所有厂商兼容。

## 范围与取舍

默认主屏保留终端历史；屏外旧卡片保留当时状态。全屏由应用维护阅读位置和选择。配置热重载仅处理资源与校验，Python 和构造期设置需要重启。

权限提供应用审计，不隔离 OS 进程；文件快照覆盖受支持写工具，不覆盖任意 Shell/MCP 副作用。单文件原子恢复不等于多文件事务。

入梦只处理当前打开项目的有效资料，按项目排序串行。模型可读受限代码，不能写源码、执行测试或自主部署。用户档案需明确原话，项目状态需当前有效依据，候选不冒充已验证结论。仅发送消息或显式 stop 暂停当前窗口；输入草稿不打断。

首版无自主实验、候选代码审批、独立候选重试、向量召回系统或自动训练模型权重。使用微调模型是连接选择，不能据此声称入梦在线训练了模型。

## 验收目标

- 发送、流式显示、工具收尾和取消保持输入可用；真实终端体验独立验收。
- 自然结束、截断、空答复和错误有明确状态，残缺调用不执行。
- 压缩后 resume 恢复实际有效视图，原始历史仍可追溯。
- 风险策略在真实调度链生效，拒绝和审批取消不默许执行。
- 入梦卡片可恢复，依据/候选/入档状态明确；新资料与未完成事项可续做。
- 文档命令和配置与工作树一致；效果指标需对照任务、环境和测量方法。

长期待验证内容以 [STATUS](development/STATUS.md) 为当前入口。产品范围变更遵循 [开发工作流](development/WORKFLOW.md)，不将历史设计或外部框架特性直接写成已实现能力。
