## 阅读与维护约定

先读 08 的装配流程，再读 01 的单轮流程；其余模块按当前问题进入。每篇至少说明职责、当前机制、接口、失败边界和验证入口；章节按内容组织。

接口以源码实际签名为准；测试通过只能证明测试覆盖的行为。离线测试不等于真实模型、MCP 服务或终端的在线验收。性能数字应同时注明输入规模、环境和测量方法，不能从局部函数推广成产品整体提速。

开发、修复与文档维护遵循 [开发工作流](../development/WORKFLOW.md)。当前说明随代码改写，本次设计与历史记录分别保存；跨模块行为明确由哪个模块负责。

验证方式见 [TESTING](../development/TESTING.md)，未完成与未验证工作见 [STATUS](../development/STATUS.md)。用户操作从 [用户指南](../user/README.md) 进入；重要取舍与典型诊断通过 [总导航](../README.md) 查阅，当前模块不承担修改流水账。
